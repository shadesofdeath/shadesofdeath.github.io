Privacy policy

The Düşün Bakalım / Stickstory upload tool is a private tool used only by the owner of these YouTube channels.

What the tool accesses

With the owner's permission (Google OAuth, YouTube scope) the tool uploads the owner's videos to the owner's own channels, sets thumbnails and reads the channel name to make sure each video goes to the right channel.

What it stores

The OAuth token is stored only as an encrypted secret of the owner's own GitHub repository. No data of any other person is collected, stored, shared or sold.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Google API data use follows the Google API Services User Data Policy, including the Limited Use requirements.
